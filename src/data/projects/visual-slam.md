## Overview

This project studies spatially balanced ORB feature selection for visual SLAM. It integrates SSC-based adaptive non-maximal suppression into the ORB keypoint selection stage of ORB-SLAM3, with the goal of improving feature coverage and tracking stability.

## References

- Campos, C. et al. (2021). ORB-SLAM3: An accurate open-source library for visual, visual-inertial and multi-map SLAM. *IEEE Transactions on Robotics*, 37(6), 1874–1890.
